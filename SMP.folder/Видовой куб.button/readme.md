# Скрипт Видовой штурвал

## Назначение:
Обеспечивает удобное и наглядное переключение между стандартными видами (изометрии, виды сбоку, сверху, снизу), а также управление визуальными стилями в 3D-виде программы Renga.

## Технические детали и логика работы:
Скрипт реализует независимое полупрозрачное окно (WinForms), которое выводится поверх основного окна Renga.

**Позиционирование интерфейса:**
Скрипт использует системные вызовы Windows API (`GetForegroundWindow` и `GetWindowRect`), чтобы найти главное окно Renga и расположить штурвал в его левом верхнем углу (с отступом под вкладки), избегая перекрытия стандартных панелей. Применение WinAPI позволило избежать ошибок компиляции, связанных с отсутствием `System.Diagnostics` во встроенном компиляторе плагинов.

**Сложная геометрия штурвала (UI):**
Интерфейс поддерживает 26 ракурсов. Для точной отрисовки этих зон при наведении или активности используются `GraphicsPath` и отсечения `Region`. Например, заливка зон "внутреннего кольца" динамически исключает (Region Exclude) 4 внутренние круглые кнопки, чтобы подсветка не "заползала" под них и они оставались полностью независимыми. 
Шрифт контекстного меню зафиксирован в 9pt (`Segoe UI`) с плоским рендерингом для независимости от масштабирования экранов (DPI).
В нижней части штурвала реализована **динамическая текстовая подсказка**, которая всегда словами пишет, на какую зону наведен курсор или какой вид сейчас активен (с приставкой `~` для приближенных видов).

**Перемещение окна и защита от дублирования:**
Реализована логика drag-and-drop: штурвал можно перетаскивать левой кнопкой мыши за любое свободное место. Также в коде предусмотрен паттерн Singleton: если пользователь случайно нажмет на кнопку плагина несколько раз, старое окно будет корректно закрыто перед открытием нового, чтобы не плодить дубликаты интерфейса.

**Обратная связь (Отображение текущего вида):**
Поскольку Renga API не предоставляет событий изменения положения камеры, реализован поллинговый механизм. Таймер каждые 100 мс считывает текущую позицию камеры (`Position`) и точку фокусировки (`FocusPoint`). На их основе строится вектор взгляда, который нормализуется и сравнивается через скалярное произведение (Dot Product) с 26-ю эталонными направлениями штурвала. 
В интерфейсе реализованы **3 градации цветовой подсветки**:
1. **Зеленый цвет (Активный вид):** Практически абсолютное совпадение вектора (Dot Product > 0.999). Означает, что камера точно зафиксирована в одном из 26 стандартных ракурсов.
2. **Желтый цвет (Ближайший вид):** Высокое совпадение (Dot Product > 0.90). Показывает ближайший к текущему положению камеры ракурс, если пользователь немного повернул модель вручную.
3. **Синий цвет (Наведение):** Реакция на наведение курсора мыши (Hover-эффект) для удобства выбора зоны.

**Управление камерой (`LookAt`):**
При переключении видов вызывается `Camera.LookAt(Target, Position, Up)`. Особое внимание уделено вектору `Up` (Верх):
- Для всех **угловых и боковых видов** (экватор) верхом выступает ось **Z**, что дает классическое CAD-отображение (Z-up).
- Для чистых видов **Сверху** и **Снизу** Z-вектор не может быть верхом. Поэтому скрипт принудительно задает вектор `Up` как **Север (ось Y = -1)**, чтобы исключить поворот сцены на 180 градусов, гарантируя, что Север на плане всегда смотрит вверх монитора.

## Схема направлений штурвала (Карта зон):
Интерфейс штурвала состоит из концентрических зон. Клик по каждой зоне переводит камеру в соответствующий ракурс:

| Зона штурвала | Соответствующие виды (Ракурсы) |
| :--- | :--- |
| **Центральный квадрат** | Строго **Сверху** |
| **4 круглые кнопки (крест)** | Строгие виды сбоку: **Спереди, Сзади, Слева, Справа** |
| **Внутреннее кольцо (ребра)** | Виды сверху-сбоку: **Сверху спереди, Сверху сзади, Сверху слева, Сверху справа** |
| **Внутреннее кольцо (углы)** | Угловые виды сбоку: **Спереди слева, Спереди справа, Сзади слева, Сзади справа** |
| **Внешнее кольцо (ребра)** | Виды снизу-сбоку: **Снизу спереди, Снизу сзади, Снизу слева, Снизу справа** |
| **Внешнее кольцо (углы)** | Угловые виды снизу: **Снизу спереди слева, Снизу сзади справа** и т.д. |
| **Внешний ободок (край)** | Строго **Снизу** |

## Алгоритм работы:
1. Перейдите в 3D-вид в Renga.
2. Нажмите на кнопку плагина "Видовой штурвал" (иконка кубика).
3. В левом верхнем углу появится штурвал. 
4. Наводите курсор на сегменты штурвала — они будут подсвечиваться.
5. Нажмите ЛКМ на нужный сегмент, чтобы мгновенно перевести камеру в этот ракурс.
6. Для смены стиля отображения нажмите ПКМ по штурвалу и выберите стиль.
7. Чтобы закрыть штурвал, выберите в меню ПКМ пункт "Закрыть штурвал" (или повторно нажмите кнопку запуска на панели плагинов).
